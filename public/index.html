ABOUT THE PROJECT

Machine Learning for Educational Health Insights

HeartPredict AI is an educational machine learning project designed to demonstrate how health-related features can be processed and analyzed using a classification model.

The application uses a Random Forest model together with data preprocessing to generate a prediction based on the information entered by the user.
